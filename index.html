云端自动同步

纯前端直连，不用搭服务器。三条通道任选一条：国内优先 Gitee；GitHub 适合有梯子的环境；自定义可挂 Cloudflare Worker。云端只存一份 JSON，数据始终在你自己的账号里。
如何花 30 秒在 Gitee（码云）拿到免费 Token
  1. 打开 gitee.com 并登录（微信 / 手机号都行，不用备案）。
  2. 右上头像 → 设置 → 左侧「私人令牌」→ 生成新令牌，勾 gists 和 projects 两项，提交后复制那串字符（只显示一次）。
  3. 粘到上面的输入框，云端位置留空，点「一键初始化云端仓库」。第一台电脑会新建云端仓库；换电脑 / 换浏览器时也只填令牌，它会自动找到已有仓库并拉下数据，不会另建一个。
自动创建会先试「代码片段」，被 Gitee 打回就自动改走「私有仓库」（仓库名 niuma-workbench-sync）。若报「跨域 / CORS」：多为单位网络或插件拦截，改用「自定义接口」通道（Worker 代理）效果一样。
GitHub 在国内部分网络需要代理；能直连 Gitee 就优先用 Gitee。
